# Probability-simulations

This repository contains interactive Python notebooks demonstrating probabilistic concepts through simulations and visualizations.

## 🧠 Contents

- Coin flip simulation with convergence toward expected probability
- Dice roll simulation with empirical vs. theoretical distribution
- Visual plots to support intuition behind randomness and probability

## 📦 Dependencies

To run the notebook, you'll need:

- Python 3.x
- numpy
- matplotlib
- seaborn
- pandas
- scipy

Install them using:

```bash
pip install numpy matplotlib seaborn pandas scipy
